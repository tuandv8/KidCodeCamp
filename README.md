# Code Adventure 🚀

A playful visual-programming learning app for young children.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server.

## GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html` and `README.md`.
3. Enable **Settings → Pages → Deploy from branch → main / root**.
4. Open the generated GitHub Pages URL.

The current MVP is fully static and stores demo progress in `localStorage`.

## MVP features

- Adventure-style home map
- Campaign level
- Visual command blocks
- Animated robot execution
- Success celebration / confetti
- Progress persistence
- Responsive mobile layout
- No backend required
